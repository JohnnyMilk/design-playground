# 編輯工站文字

唯一的工站文字來源：`flexfill/dist/stations.json`（GitHub 的 main 分支）。

1. 在 GitHub 開啟此檔案，按鉛筆編輯。
2. 修改 `name`（工站名稱）或 `description`（敘述）。
3. 選 Commit changes，提交到 main。若另開分支，需合併回 main 才會生效。
4. 重新整理展示網站。GitHub Pages 與原 Sites 網址都會重新讀取 GitHub main 的檔案；無須重新建模或由助理重新發布 Sites。GitHub 的快取或 Pages 部署可能造成短暫延遲。

保留五個工站的 `id`："01"、"02"、"03"、"04"、"05"。不要刪除或更改 id；陣列次序可調整，網站依 id 對應模型及動線。

JSON 使用英文雙引號。文字中的雙引號寫成 `\"`，換行寫成 `\n`；最後一個欄位後不要加逗號。不要加註解。文字作為純文字顯示，不支援 HTML。

讀取 GitHub 失敗或格式錯誤時，網頁顯示提示，並嘗試使用網站隨附的 stations.json；若備援也無法讀取，仍保留 3D 模型及工站按鈕並顯示載入失敗說明。網頁不定時自動刷新，需重新整理頁面取得新文字。

此 JSON 控制五個工作站的按鈕名稱、工作站說明、選取時的視角標題，以及動線上的工作站名稱。首頁總介紹與各段動作名稱仍由網頁程式管理。
