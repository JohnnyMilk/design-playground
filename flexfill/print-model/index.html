列印與組裝

  1. 使用 H2C 正確機型及實際噴嘴設定。先以 PLA、0.4 mm 噴嘴、0.16 mm 層高、3 道牆作為試印起點；底面向下。細柱與坡道需視切片增加 brim。
  2. 開啟支撐並逐層檢查：中央取紙橫樑、上層輸送底面、充填與膠塞頭、供塞軌道、HMI 背面及出料坡道。部分支撐位於雙層通道內，需確認能拆除；只支撐熱床可能漏掉這些區域。
  3. 先列印兩片定位片，確認底面凹槽配合。三模組接縫 0.24 mm，定位片每側預留 0.2 mm；確認上下層動線對齊後再黏合。定位片為輔助定位，非鎖扣。
  4. 網格封閉不等於已能直接列印。檢查薄針、局部薄壁、橋接、象腳與支撐可達性，試印後才決定正式參數。未提供已驗證的 3MF 或 G-code。

縮尺基本元件最薄尺寸加厚至 1.2 mm；L 型底座厚 3.2 mm，坡道加設永久支柱。這是靜態桌上展示模型，細針與載具不具實際運動功能。
