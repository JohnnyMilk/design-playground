PROJECT 02 / GAME DESIGN

Positional
Dynamics

一款以職業配置、三排站位與路線選擇為核心的自動戰鬥策略遊戲。玩家不必逐次下達攻擊指令，而是在戰鬥前安排隊伍，讓不同站位的技能產生策略組合。

4 個固定職業前／中／後 3 站位自動戰鬥獨立暴擊率升級替換技能

遊戲如何進行？

一個簡單的循環，串起編隊、探索、戰鬥與成長。

01　配置職業站位→02　選擇地圖路線→03　自動戰鬥→04　累積經驗→05　替換技能
目前主要設計方向：四職業獨立升級；每個站位技能有自己的暴擊率，暴擊時施放特殊效果。不使用充能條。技能與平衡數值仍屬設計提案。

企劃設定資料庫

選一個主題直接閱讀。所有主要設定都在下一層，不必繼續往下鑽。

01 / CLASSES

四職業初始技能

騎士、祭司、遊俠、法師：各站位的一般技能、暴擊技能與獨立暴擊率。

閱讀設定 ↗02 / PROGRESSION

完整技能升級樹

每職業三條站位路線，I–III 階技能替換；共 36 組進化技能。

閱讀設定 ↗03 / BALANCE

暴擊與數值平衡

獨立暴擊率、期望傷害、治療、減傷、控制及保底機制。

閱讀設定 ↗04 / SYSTEMS

戰鬥與經驗規則

敏捷行動順序、技能判定、獨立經驗、升級門檻與換位規則。

閱讀設定 ↗05 / DEVELOPMENT

開發規劃與測試

原型優先順序、測試指標，以及需要先驗證的核心玩法。
