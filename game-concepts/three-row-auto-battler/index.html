DESIGN PLAYGROUND / GAME CONCEPTv0.1 · 概念原型

三排職業，
一條由你決定的戰鬥路線。

自由配置前、中、後排職業。每種職業因站位與充能狀態產生不同技能，戰鬥依敏捷自動進行；下方地圖由你規劃遇敵順序，升級再選擇三種強化之一。

⚔️ 上方｜自動戰鬥編隊

依敏捷出手
選擇技能狀態
祭司・前排・一般能力自身防禦

對自己施放防禦效果。

點擊不同站位及技能狀態，查看祭司的技能差異。此處只是技能示例；實際編隊規則與數值未定。

🗺️ 下方｜地圖路徑

一次規劃起點到終點
遭遇順序：敵人 A → 敵人 B → 敵人 D

兩條路線僅示範「改變路徑影響遇敵順序」，不是完整尋路、碰撞或實際地圖系統。

⬆️ 升級｜三選一

目前選擇：攻擊強化

示意 UI，可點選切換；尚未定義實際強化池與作用對象。

📋 設計定義與待討論

已提出：三格自由編隊、站位對應技能、一般與充能技能、敏捷決定出手、全自動戰鬥、地圖規劃遇敵順序、升級三選一。

  1. 集氣累積、觸發、消耗與技能選擇方式。
  2. 完整職業表、站位技能、目標選取與數值。
  3. 敵方隊形、職業連攜與可否重複職業。
  4. 路線避敵／改線／事件節點等規則。
  5. 升級對象、勝敗條件與進度繼承。
