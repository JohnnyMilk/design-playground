四色技能與裝備槽

主角有紅、藍、綠、黃四個技能槽。收集的技能依顏色限制裝備；每種顏色有獨立魔力池，施放時支付技能需求的魔力。

紅色
火焰／力量
藍色
冰霜／奧術
綠色
生命／自然
黃色
雷電／神聖

顏色主題是設計方向，不是硬性限制；各色可出現攻擊、防禦、治療或控制技能。

三種裝備方式

TYPE A

單色技能

只能放入指定顏色槽，只佔一格。例：火球裝在紅槽，消耗紅色魔力。

TYPE B

雙色擇一

可以選兩種指定顏色中的一格裝備，但只佔一格。例：風暴箭可裝藍或黃，消耗所選槽顏色的魔力。

TYPE C

雙色佔槽

同時佔用兩個指定顏色槽，視為一個技能，不會重複施放。例：元素風暴佔紅＋藍，施放需同時支付兩色魔力。
