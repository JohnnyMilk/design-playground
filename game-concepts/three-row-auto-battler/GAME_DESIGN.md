# 三排職業自動戰鬥 × 路徑規劃 — 遊戲設計草案 v0.1

> 狀態：概念探索｜最後整理：2026-10-20。本文區分「已提出設定」、「示例」與「待決事項」，避免將尚未確認的構想當成規格。

## 核心概念
玩家自由將職業配置於**前、中、後排各一格**。進入戰鬥後全自動出手，依**敏捷**決定順序。**站位 × 能力狀態**（一般／充能後）會改變同一職業的施放技能。畫面上方顯示戰鬥，下方顯示地圖路徑規劃。玩家可一次從起點拉到終點，依路線決定遇敵順序；升級時採 Roguelike 的三選一。

參考方向：《聖獸之王》的編隊與自動戰鬥、《倖存者》類型遊戲的升級三選一。此處是機制參考，不代表複製其規則。

## 戰鬥配置（已提出）
| 編隊格 | 職業 | 能力選擇 |
|---|---|---|
| 前排 | 玩家自由配置 | 依前排的一般／充能技能 |
| 中排 | 玩家自由配置 | 依中排的一般／充能技能 |
| 後排 | 玩家自由配置 | 依後排的一般／充能技能 |

- 三格各自可放不同職業；是否允許重複職業尚未定案。
- 每個職業在前、中、後排可能擁有不同技能；有些職業的中後排技能可相同。
- 角色按敏捷決定出手順序；敏捷同值如何處理待定。
- 一般技能與集氣後技能效果可能不同；充能獲得、消耗、觸發時機待定。

### 祭司技能（示例，非定稿）
| 站位 | 一般能力 | 充能完成後 |
|---|---|---|
| 前排 | 對自己施放防禦 | 對前中後三排施放防禦 |
| 中排 | 治療前排隊友 | 將前排隊友補滿生命，或復活 |
| 後排 | 與中排相同：治療前排 | 與中排相同：補滿生命，或復活 |

> 「補滿／復活」目前為兩個構想，尚未決定是擇一、條件觸發或兩個技能。

## 地圖移動（已提出）
- 玩家在下方地圖從起點一次規劃到終點。
- 路線經過的敵人決定戰鬥遭遇順序。
- 是否可避怪、改線、經過重複節點及路徑成本，目前待定。

## 升級（已提出）
- 達到升級條件時，提供**三選一**強化。
- 以下只是 UI 佔位示例：攻擊提升／敏捷提升／充能效率提升。強化池、稀有度、目標範圍與升級觸發條件皆待定。

## 待決清單
1. 充能如何累積、何時使用、是否由玩家事先指定條件。
2. 職業清單、各站位技能、數值與戰鬥目標選取規則。
3. 多職業連攜與重複職業限制。
4. 敵人是否也採前中後排、敏捷規則與技能機制。
5. 地圖是否可避敵、重畫路線、遇敵後暫停、事件分支。
6. 三選一強化是全隊、單一職業、單一位置或跨局成長。
7. 勝敗條件、復活時機、每場戰鬥結束後狀態如何繼承。
